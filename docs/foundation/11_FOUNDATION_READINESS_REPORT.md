## 6. التوصيات

1. **لا يبدأ Sprint 1** قبل إنجاز العناصر الحرجة والعالية.
2. إنشاء **Sprint 0.5** لمعالجة العناصر الحرجة والعالية (2–3 أسابيع).
3. بعد إكمال Sprint 0.5، إعادة تقييم الجاهزية.
4. عند الوصول إلى **≥ 95%**، البدء في Sprint 1 (Core Infrastructure).

## 7. أهم 20 نقطة يجب تنفيذها في Sprint 1 / Sprint 0.5

1. إغلاق `/api/password` reset/force-reset endpoints بمصادقة صحيحة.
2. تقييد CORS على endpoints المصادقة.
3. توحيد جداول `subscriptions` (legacy vs V3).
4. توحيد جداول `scenarios` (legacy vs V3).
5. توحيد جداول `ingredients` / `menu_items`.
6. تصحيح توجيه V3 إلى `v3/api/index.js`.
7. توحيد منطق `verifyAdmin` / `verifyAdminStrict`.
8. توحيد إصدارات `stripe` و `nodemailer` و `jest`.
9. نقل `country-platforms-data.js` و `shared-platforms.js` إلى قاعدة البيانات.
10. إنشاء Unified Data Layer schema.
11. إنشاء Global Object Registry (sequences).
12. تطبيق Business Rules Catalog في الكود.
13. جعل AI prompts ثنائية اللغة.
14. مراجعة RLS على جميع الجداول الحساسة.
15. إنشاء Data Source Registry في النظام.
16. توحيد أشكال ردود APIs.
17. إضافة/حذف الاعتماديات المفقودة/الميتة.
18. توحيد payment webhooks.
19. إنشاء views لقراءة بيانات المستخدمين.
20. إضافة FK indexes.
