- نوع بيانات.
- وحدة قياس.
- قواعد الإلزامية.
- مصدر البيانات.
- طريقة الاستخدام.

## 10. ملاحظات عامة

- جميع المبالغ تُخزن بالعملة الأساسية للمشروع (SAR افتراضياً) مع إمكانية تحويل.
- النسب تُخزن كأرقام عشرية (مثال: 15% = 0.15).
- التواريخ تُخزن بتنسيق `timestamptz`.
- الحقول المحسوبة لا تُعدل يدوياً؛ يتم إعادة حسابها.
