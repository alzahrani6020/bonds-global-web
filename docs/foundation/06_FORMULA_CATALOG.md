## 3. المعادلات المالية

### F-001 — Return on Investment (ROI)

| البند | التفاصيل |
|---|---|
| **الاسم** | ROI |
| **الشرح** | العائد على الاستثمار كنسبة مئوية. |
| **المصدر** | المعايير المحاسبية الدولية. |
| **المتغيرات** | `Net Profit`، `Investment Cost` |
| **الصيغة** | `ROI = (Net Profit / Investment Cost) × 100%` |
| **الافتراضات** | الأرباح والتكاليف بنفس العملة ونفس الفترة. |
| **القيود** | لا يأخذ في الاعتبار القيمة الزمنية للنقود. |
| **الاستخدام** | الجدوى، التقارير، التوصيات. |

### F-002 — Internal Rate of Return (IRR)

| البند | التفاصيل |
|---|---|
| **الاسم** | IRR |
| **الشرح** | معدل الخصم الذي يجعل NPV = 0. |
| **المصدر** | Corporate Finance (Berk & DeMarzo). |
| **المتغيرات** | `CF_t` التدفق النقدي في الفترة t، `t` الفترة الزمنية |
| **الصيغة** | `NPV = Σ(CF_t / (1 + IRR)^t) = 0` |
| **الافتراضات** | التدفقات النقدية معروفة. |
| **القيود** | قد يعطي حلين أو لا حل؛ حساس للتوقيت. |
| **الاستخدام** | الجدوى، التقييم، التوصيات. |

### F-003 — Net Present Value (NPV)

| البند | التفاصيل |
|---|---|
| **الاسم** | NPV |
| **الشرح** | القيمة الحالية للتدفقات النقدية المستقبلية. |
| **المصدر** | Corporate Finance (Berk & DeMarzo). |
| **المتغيرات** | `CF_t`، `r` معدل الخصم، `t`، `Initial Investment` |
| **الصيغة** | `NPV = -Initial Investment + Σ(CF_t / (1 + r)^t)` |
| **الافتراضات** | معدل الخصم ثابت. |
| **القيود** | يعتمد بشكل كبير على `r`. |
| **الاستخدام** | الجدوى، التقييم. |

### F-004 — Discounted Cash Flow (DCF)

| البند | التفاصيل |
|---|---|
| **الاسم** | DCF |
| **الشرح** | تقييم القيمة الحالية للتدفقات النقدية المستقبلية. |
| **المصدر** | Valuation (McKinsey). |
| **المتغيرات** | `CF_t`، `r`، `g` معدل النمو الطويل الأجل، `Terminal Value` |
| **الصيغة** | `Value = Σ(CF_t / (1 + r)^t) + Terminal Value / (1 + r)^n` |
| **الافتراضات** | توقعات تدفقات نقدية موثوقة. |
| **القيود** | حساس جداً للافتراضات. |
| **الاستخدام** | التقييم بالمنهجية الدخلية. |

### F-005 — Debt Service Coverage Ratio (DSCR)

| البند | التفاصيل |
|---|---|
| **الاسم** | DSCR |
| **الشرح** | قدرة المشروع على سداد الديون. |
| **المصدر** | Banking Credit Analysis. |
| **المتغيرات** | `NOI` صافي الدخل التشغيلي، `Debt Service` السداد السنوي |
| **الصيغة** | `DSCR = NOI / Debt Service` |
| **الافتراضات** | NOI ثابت أو متوقع. |
| **القيود** | لا يأخذ في الاعتبار التقلبات الموسمية. |
| **الاستخدام** | التمويل، الجدوى، البنوك. |

### F-006 — Loan-to-Value (LTV)

| البند | التفاصيل |
|---|---|
| **الاسم** | LTV |
| **الشرح** | نسبة مبلغ القرض إلى قيمة الأصل. |
| **المصدر** | Mortgage / Real Estate Finance. |
| **المتغيرات** | `Loan Amount`، `Asset Value` |
| **الصيغة** | `LTV = Loan Amount / Asset Value` |
| **الافتراضات** | القيمة السوقية محدثة. |
| **القيود** | قيمة الأصل قد تتغير. |
| **الاستخدام** | التمويل العقاري، التقييم. |

### F-007 — Payback Period

| البند | التفاصيل |
|---|---|
| **الاسم** | Payback Period |
| **الشرح** | الوقت اللازم لاسترداد الاستثمار. |
| **المصدر** | Capital Budgeting. |
| **المتغيرات** | `Initial Investment`، `Annual Cash Flow` |
| **الصيغة** | `Payback = Initial Investment / Annual Cash Flow` |
| **الافتراضات** | التدفقات النقدية منتظمة. |
| **القيود** | لا يأخذ في الاعتبار القيمة الزمنية للنقود. |
| **الاستخدام** | الجدوى، التقارير. |

### F-008 — Break-even Point

| البند | التفاصيل |
|---|---|
| **الاسم** | Break-even |
| **الشرح** | حجم المبيعات اللازم لتغطية التكاليف. |
| **المصدر** | Managerial Accounting. |
| **المتغيرات** | `Fixed Costs`، `Price per Unit`، `Variable Cost per Unit` |
| **الصيغة** | `Break-even Units = Fixed Costs / (Price - Variable Cost)` |
| **الافتراضات** | التكاليف ثابتة أو خطية. |
| **القيود** | لا يعكس تغيرات السعر أو الطلب. |
| **الاستخدام** | الحاسبات، الجدوى، التوصيات. |

### F-009 — EBITDA

| البند | التفاصيل |
|---|---|
| **الاسم** | EBITDA |
| **الشرح** | الأرباح قبل الفوائد والضرائب والاستهلاك والإطفاء. |
| **المصدر** | IFRS / GAAP. |
| **المتغيرات** | `Revenue`، `Operating Expenses` |
| **الصيغة** | `EBITDA = Revenue - Operating Expenses (excluding D&A)` |
| **الافتراضات** | البيانات المحاسبية دقيقة. |
| **القيود** | لا يعكس الاستهلاك. |
| **الاستخدام** | التقييم، التمويل، التقارير. |

### F-010 — Depreciation (Straight-Line)

| البند | التفاصيل |
|---|---|
| **الاسم** | Depreciation |
| **الشرح** | توزيع تكلفة الأصل عمره الإنتاجي. |
| **المصدر** | IFRS / GAAP. |
| **المتغيرات** | `Cost`، `Salvage Value`، `Useful Life` |
| **الصيغة** | `Annual Depreciation = (Cost - Salvage Value) / Useful Life` |
| **الافتراضات** | عمر افتراضي ثابت. |
| **القيود** | قد لا يعكس التآكل الفعلي. |
| **الاستخدام** | الجدوى، التقييم. |

## 4. معادلات التقييم

### F-011 — Book Value

| البند | التفاصيل |
|---|---|
| **الاسم** | Book Value |
| **الشرح** | القيمة الدفترية للأصل. |
| **المصدر** | IFRS. |
| **المتغيرات** | `Cost`، `Accumulated Depreciation` |
| **الصيغة** | `Book Value = Cost - Accumulated Depreciation` |
| **الاستخدام** | التقييم، المحاسبة. |

### F-012 — Residual Value

| البند | التفاصيل |
|---|---|
| **الاسم** | Residual Value |
| **الشرح** | القيمة المتوقعة في نهاية العمر الاقتصادي. |
| **المصدر** | Valuation Standards. |
| **المتغيرات** | `Initial Value`، `Depreciation Rate`، `Age` |
| **الصيغة** | `Residual Value = Initial Value × (1 - Depreciation Rate)^Age` |
| **الاستخدام** | التقييم، التأجير. |

### F-013 — Liquidation Value

| البند | التفاصيل |
|---|---|
| **الاسم** | Liquidation Value |
| **الشرح** | القيمة المتوقعة عند بيع الأصل في ظروف قسرية. |
| **المصدر** | IVS. |
| **المتغيرات** | `Market Value`، `Discount Factor` |
| **الصيغة** | `Liquidation Value = Market Value × (1 - Discount Factor)` |
| **الاستخدام** | التقييم، إنقاذ الأصول. |

### F-014 — Replacement Cost

| البند | التفاصيل |
|---|---|
| **الاسم** | Replacement Cost |
| **الشرح** | تكلفة استبدال الأصل بأصل جديد مماثل. |
| **المصدر** | IVS. |
| **المتغيرات** | `New Asset Cost`، `Depreciation`، `Obsolescence` |
| **الصيغة** | `Replacement Cost = New Asset Cost - Depreciation - Obsolescence` |
| **الاستخدام** | منهجية التكلفة. |

### F-015 — Income Approach

| البند | التفاصيل |
|---|---|
| **الاسم** | Income Approach |
| **الشرح** | تقييم القيمة بناءً على التدفقات النقدية المستقبلية. |
| **المصدر** | IVS. |
| **المتغيرات** | `NOI`، `Cap Rate` أو `r`، `g` |
| **الصيغة** | `Value = NOI / Cap Rate` أو DCF |
| **الاستخدام** | العقارات التجارية، الأصول المدرة للدخل. |

### F-016 — Cost Approach

| البند | التفاصيل |
|---|---|
| **الاسم** | Cost Approach |
| **الشرح** | تقييم القيمة بناءً على تكلفة البناء. |
| **المصدر** | IVS. |
| **المتغيرات** | `Land Value`، `Construction Cost`، `Depreciation` |
| **الصيغة** | `Value = Land Value + Construction Cost - Depreciation` |
| **الاستخدام** | العقارات الجديدة، المصانع. |

### F-017 — Market Approach

| البند | التفاصيل |
|---|---|
| **الاسم** | Market Approach |
| **الشرح** | تقييم القيمة بناءً على المقارنات السوقية. |
| **المصدر** | IVS. |
| **المتغيرات** | `Comparable Price`، `Adjustments`، `Area` |
| **الصيغة** | `Value = Comparable Price × Adjustments` |
| **الاستخدام** | العقارات السكنية، الأصول المتداولة. |

---

## 5. ملاحظات

- جميع النسب تُخزن كقيم عشرية (مثال: 15% = 0.15).
- جميع العملات تُخزن بالريال السعودي افتراضياً مع إمكانية التحويل.
- المعادلات تُطبق ضمن محركات محددة ولا تُكرر في الصفحات.
