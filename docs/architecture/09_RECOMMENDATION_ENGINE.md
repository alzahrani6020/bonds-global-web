## 1. الهدف

إصدار توصيات اقتصادية واستثمارية تلقائية بناءً على تحليل جميع المحركات، مع شرح واضح لأسباب التوصية.

---

## 2. النطاق

- جميع المشاريع والأصول.
- جميع مراحل دورة القرار.
- جميع المستخدمين (مستثمر، مصرفي، شركة، فرد).

---

## 3. أنواع التوصيات

| التوصية | الوصف |
|---|---|
| **Buy / شراء** | الأصل مناسب للشراء بناءً على التقييم والسوق. |
| **Sell / بيع** | الأصل مبالغ في قيمته أو المخاطر تتزايد. |
| **Hold / احتفاظ** | الأصل جيد والاحتفاظ به أفضل. |
| **Finance / تمويل** | يوجد هيكل تمويل مناسب للمشروع. |
| **Partner / شريك** | يُفضّل الدخول بشريك لتقليل المخاطر. |
| **Expand / توسع** | المشروع يستحق التوسع. |
| **Exit / تخارج** | يُنصح بالخروج من الاستثمار. |
| **Develop / تطوير** | يمكن زيادة القيمة عبر التطوير. |
| **Restructure / إعادة هيكلة** | المشروع يحتاج إعادة هيكلة للاستمرار. |
| **Wait / انتظار** | البيانات غير كافية أو السوق غير مناسب حالياً. |

## 5. منطق التوصية

### 5.1 Rule-Based Scoring
- كل توصية تحصل على درجة بناءً على قواعد مثل:
  - إذا IRR > 20% و Risk < متوسط → Buy.
  - إذا Risk > عالي → Hold أو Restructure.
  - إذا القيمة السوقية < القيمة الدفترية → Sell.

### 5.2 AI Layer
- AI يُقدم تحليلاً نوعياً ويؤكد أو يشكك في القاعدة.
- AI لا يُغيّر الدرجة.

### 5.3 Constraints
- القيود التنظيمية، المالية، أو المستخدم قد تُبطل بعض التوصيات.

## 7. قواعد التطوير

- كل توصية يجب أن تكون قابلة للتفسير.
- التوصية يجب أن تأخذ في الاعتبار Confidence Score.
- لا يُسمح بتقديم توصية بناءً على محرك واحد فقط.
- يجب تسجيل كل توصية في Decision Memory.
