# إطار تقييم الجدارة الائتمانية المتوافق مع البنوك العربية

> نسخة موحدة ومتوافقة مع واقع البنوك والمؤسسات المالية العربية.  
> تدمج المعايير العالمية (ECB / Fed / JPMorgan) مع خصوصية المنطقة العربية: الضمانات، الكفالات، الالتزام التنظيمي، والامتثال الشرعي.

---

## 1. الفكرة الأساسية

التقييم العالمي يقيس **احتمالية التخلف عن السداد (PD)**.  
التقييم العربي يضيف إلى ذلك:

- **الضمانات والكفالات** (تغطية المخاطر).
- **السمعة والعلاقة مع البنك** (Character محلي).
- **الالتزام التنظيمي والضريبي**.
- **الامتثال الشرعي** (للبنوك الإسلامية).
- **مخاطر القطاع والدولة**.

**الهدف:** تقييم واحد يفهمه البنك العربي، ويستفيد منه المقترض، ويُنتج قرارًا واضحًا: **قبول، رفض، أو قبول بشروط**.

## 2. البنية الموحدة للتقييم

### 2.1 المحاور العامة (تنطبق على الأفراد والشركات)

| المحور | الوزن | الشرح |
|---|---|---|
| **القدرة المالية** | 25% | الدخل/الأرباح، التدفق النقدي، القدرة على السداد |
| **التاريخ الائتماني** | 20% | تقرير مكتب الائتمان، سجل السداد |
| **الضمانات والكفالات** | 20% | العقار، الودائع، الكفيل، الأصول |
| **السمعة والحوكمة** | 15% | سمعة المقترض، سجل العمل، الحوكمة |
| **مخاطر القطاع والدولة** | 10% | استقرار القطاع، المدينة، البلد |
| **الامتثال الشرعي / التنظيمي** | 5% | ترخيص النشاط، امتثال Sharia |
| **جاهزية التمويل** | 5% | اكتمال المستندات، جاهزية العقد |

**المجموع: 100%**

## 3. تقييم الأفراد — النسخة العربية

### 3.1 الأبعاد والأوزان

| البُعد | الوزن | المؤشرات |
|---|---|---|
| **الدخل والاستقرار الوظيفي** | 30% | الراتب، جهة العمل (حكومي/خاص)، مدة الخدمة، نوع العقد |
| **التاريخ الائتماني** | 25% | تقرير SIMAH/AECB/I-Score، التأخرات، القروض السابقة |
| **الالتزامات الحالية** | 20% | DTI، الأقساط الشهرية، بطاقات الائتمان |
| **الضمانات والأصول** | 15% | العقار، الودائع، المركبة، الاستثمارات |
| **السمعة والاستقرار الاجتماعي** | 10% | مدة الإقامة، الحالة الاجتماعية، الكفيل/الضامن |

### 3.2 درجات التقييم للأفراد

| الدرجة | النطاق | قرار البنك |
|---|---|---|
| **ممتاز** | 85–100 | قبول فوري، سعر تفضيلي |
| **جيد جدًا** | 75–84 | قبول سريع |
| **جيد** | 65–74 | قبول بشروط عادية |
| **متوسط** | 50–64 | قبول بضمانات إضافية أو كفيل |
| **ضعيف** | 35–49 | رفض أو برنامج تأهيل |
| **مرفوض** | < 35 | رفض |

### 3.3 معايير خاصة بالمنطقة العربية

- **الراتب المحوّل إلى البنك** يعطي درجة أعلى من الراتب النقدي.
- **الموظف الحكومي** يُعتبر أقل مخاطر من القطاع الخاص.
- **الكفيل الموظف** يُحسّن التقييم بشكل كبير.
- **المواطن المقيم دائمًا** أفضل من وافد بعقد مؤقت.

## 4. تقييم الشركات الناشئة — النسخة العربية

### 4.1 الأبعاد والأوزان

| البُعد | الوزن | المؤشرات |
|---|---|---|
| **الفريق والمؤسسون** | 25% | خبرة المؤسسين، سجلهم، الالتزام |
| **التمويل والمستثمرون** | 20% | Runway، Burn Rate، مستثمرون سابقون، جولة تمويل |
| **السوق والمنتج** | 20% | Product-Market Fit، حجم السوق، المنافسة |
| **Traction** | 20% | MRR/ARR، عدد العملاء، معدل النمو |
| **الحوكمة والترخيص** | 15% | ترخيص، مساهمون، محاسب قانوني |

### 4.2 درجات التقييم للناشئات

| الدرجة | النطاق | القرار |
|---|---|---|
| **ممتاز** | 80–100 | جاهزة لـ Venture Debt أو تمويل حكومي |
| **جيدة** | 65–79 | قابلة للتمويل بشروط |
| **واعدة** | 50–64 | تحتاج إلى تحسين Traction |
| **عالية الخطورة** | 35–49 | تمويل مؤسسي فقط |
| **مرفوضة** | < 35 | غير جاهزة |

### 4.3 معايير خاصة بالمنطقة العربية

- وجود **ترخيص ساري** في البلد.
- تواجد **مستثمر معروف** (VC محلي أو عالمي) يزيد الثقة.
- قطاع **غير محظور** ولا يتعارض مع الشريعة.
- امتلاك **فريق محلي** يفهم السوق.

## 5. تقييم المنشآت الصغيرة والمتوسطة (SMEs) — النسخة العربية

### 5.1 الأبعاد والأوزان

| البُعد | الوزن | المؤشرات |
|---|---|---|
| **الأداء المالي** | 25% | الإيرادات، الأرباح، الهوامش، النمو |
| **التدفق النقدي والملاءة** | 20% | Current Ratio، DSCR، رأس المال العامل |
| **التاريخ الائتماني** | 20% | تقرير مكتب الائتمان، سجل دفع الموردين |
| **الضمانات والأصول** | 15% | العقار، المعدات، المخزون، الودائع |
| **الحوكمة والالتزام** | 10% | ترخيص، VAT/Tax compliance، محاسب قانوني |
| **مخاطر القطاع والدولة** | 10% | استقرار القطاع، المدينة، البيئة التنظيمية |

### 5.2 درجات التقييم للـ SMEs

| الدرجة | النطاق | قرار البنك |
|---|---|---|
| **ممتاز** | 85–100 | تمويل بفائدة تفضيلية، بدون ضمانات أو بضمانات بسيطة |
| **جيد جدًا** | 75–84 | قبول سريع |
| **جيد** | 65–74 | قبول بضمانات عادية |
| **متوسط** | 50–64 | قبول بضمانات إضافية أو كفيل |
| **ضعيف** | 35–49 | رفض أو تمويل ضمن برنامج حكومي |
| **مرفوض** | < 35 | رفض |

### 5.3 معايير خاصة بالمنطقة العربية

- **مدة عمل المنشأة**: المنشآت الأقدم من 3 سنوات تحصل على درجة أعلى.
- **التسجيل في الغرفة التجارية** إلزامي.
- **الالتزام بـ VAT والضريبة** مؤشر قوي على الحوكمة.
- **العلاقة مع البنك**: حساب نشط منذ سنوات يحسّن التقييم.
- **الكفيل الذهبي**: كفيل من ذوي الدخل المرتفع أو شركة كبيرة.

## 6. الضمانات والكفالات — التقييم العربي

### 6.1 أنواع الضمانات

| الضمان | القيمة للبنك | النسبة المالية |
|---|---|---|
| **عقار سكني/تجاري** | عالي | 70–80% من القيمة السوقية |
| **وديعة بنكية ثابتة** | عالي | 90–100% |
| **ضمان حكومي / صندوق ضمان** | عالي | 70–90% |
| **معدات / مخزون** | متوسط | 40–60% |
| **حسابات مستحقة** | متوسط | 50–70% |
| **كفيل ذو دخل مرتفع** | متوسط إلى عالي | حسب دخل الكفيل |

### 6.2 تأثير الضمان على الدرجة

| نوع الضمان | التأثير على الدرجة |
|---|---|
| عقار + كفيل | +15 إلى +25 نقطة |
| وديعة بنكية | +15 إلى +20 نقطة |
| كفيل فقط | +5 إلى +10 نقاط |
| لا يوجد ضمان | 0 |

## 7. الامتثال الشرعي (Sharia Compliance)

### 7.1 معايير الفحص الشرعي

| المعيار | الشرط |
|---|---|
| **نشاط حلال** | لا يشمل الخمر، القمار، الربا، التبغ، الأسلحة المحرمة |
| **هيكل التمويل** | يتوافق مع المرابحة، الإجارة، المشاركة، أو المضاربة |
| **عقد واضح** | لا يوجد غموض أو شروط ظالمة |
| **مجلس شرعي** | للبنوك الإسلامية فقط |

### 7.2 تأثيره على التقييم

- للبنوك الإسلامية: إذا كان النشاط غير متوافق → **رفض تلقائي**.
- للبنوك التقليدية: قد لا يؤثر مباشرة، لكن بعض البنوك تتجنب قطاعات معينة.

```text
Arab Bank Credit Score =
  (القدرة المالية × 0.25) +
  (التاريخ الائتماني × 0.20) +
  (الضمانات والكفالات × 0.20) +
  (السمعة والحوكمة × 0.15) +
```

## 11. قائمة تحقق عربية شاملة

### للأفراد
- [ ] إثبات هوية ساري.
- [ ] كشف راتب آخر 3–6 أشهر.
- [ ] خطاب من جهة العمل.
- [ ] تقرير مكتب الائتمان المحلي.
- [ ] بيان الالتزامات الحالية.
- [ ] إثبات سكن/إقامة.
- [ ] كفيل/ضامن (إن وجد).

### للناشئات
- [ ] ترخيص تجاري ساري.
- [ ] نبذة عن الفريق والمستثمرين.
- [ ] MRR/ARR و Traction.
- [ ] Runway و Burn Rate.
- [ ] محاسب قانوني.
- [ ] ضمان أو مستثمر مرجعي.

### للـ SMEs
- [ ] سجل تجاري + غرفة تجارية.
- [ ] القوائم المالية لآخر سنتين.
- [ ] كشوف بنكية 6–12 شهر.
- [ ] تقرير ائتماني للمنشأة.
- [ ] شهادة VAT/Zakat/Tax.
- [ ] عقد إيجار أو ملكية.
- [ ] ضمانات أو كفيل.

## 12. الخلاصة

الإطار العربي لا يلغي المعايير العالمية، بل **يضيف إليها طبقة محلية** تفهمها البنوك العربية:

1. **الضمانات والكفالات** ليست مكملة، بل عنصر أساسي.
2. **السمعة والعلاقة مع البنك** لها وزن حقيقي.
3. **الامتثال الشرعي** يحدد القبول في البنوك الإسلامية.
4. **الالتزام الضريبي والتنظيمي** مؤشر على الحوكمة.
5. **مخاطر القطاع والدولة** لا يمكن تجاهلها.

بهذا الإطار، يصبح تقييم Bonds Global **أداة عملية** يمكن عرضها على البنك العربي كمدخل أولي موثق، ويمكن للمقترض فهم سبب قبوله أو رفضه.
