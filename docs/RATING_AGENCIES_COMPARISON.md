# Bonds Global مقابل وكالات التصنيف الائتماني العالمية

> مقارنة مهنية بين إطار الجدارة الائتمانية في Bonds Global وبين وكالات Moody's و S&P Global Ratings و Fitch Ratings، مع تقييم بصري/تصميمي للعرض.

---

## 1. ما تركز عليه وكالات التصنيف العالمية

### 1.1 الجوهر

وكالات التصنيف الائتماني تقيس **احتمالية التخلف عن السداد (Probability of Default, PD)** لجهة إصدار دين معينة (issuer) أو لإصدار دين محدد (issue).

### 1.2 العناصر الرئيسية في عملها

| العنصر | الشرح |
|---|---|
| **Issuer Rating** | تقييم قدرة الجهة (شركة/دولة/بنك) على سداد ديونها بشكل عام. |
| **Issue Rating** | تقييم إصدار دين محدد (سند معين) يأخذ بعين الاعتبار الضمانات وترتيب السداد. |
| **Long-Term / Short-Term Ratings** | تصنيفات قصيرة وطويلة الأجل. |
| **Outlook** | توقع الاتجاه المستقبلي: Positive, Stable, Negative, Developing. |
| **Methodology Disclosure** | نشر منهجيات واضحة وشفافة للسوق. |
| **Surveillance** | مراقبة مستمرة للتصنيفات وتحديثها عند تغير الأحداث. |
| **Regulatory Oversight** | رقابة من هيئات مثل SEC (NRSRO) و ESMA و FCA. |
| **Historical Default Data** | استخدام قواعد بيانات ضخمة للتخلفات السابقة لمعايرة النماذج. |
| **Macro & Sector Analysis** | تحليل الاقتصاد الكلي والقطاع والجغرافيا. |

### 1.3 مقياس التصنيف الأساسي (مثال S&P)

```text
AAA  → أعلى درجة ائتمانية
AA   → قوية جدًا
A    → قوية
BBB  → كافية (investment grade)
BB   → عالية المضاربة
B    → مضاربة عالية
CCC  → خطر تخلف كبير
D    → متخلف عن السداد
```

Moody's و Fitch تستخدم مقاييس مشابهة برموز مختلفة قليلاً.

## 2. أين يقف عمل Bonds Global مقارنة بهذه الشركات؟

### 2.1 أوجه التشابه ✅

| Bonds Global | وكالات التصنيف |
|---|---|
| استخدام أبعاد متعددة (7 Cs) | استخدام منهجيات متعددة الأبعاد |
| تقسيم المقترضين لفئات (فرد، ناشئة، SME) | تقسيم المصدرين لقطاعات (شركات، بنوك، دول) |
| نطاق رقمي 0–100 + تصنيف حرفي/نصي | مقياس حروف + أرقام معدلة |
| Risk Rating للمشروع | Outlook / Standalone Credit Profile |
| تكامل المخاطر المالية والتشغيلية | تحليل Qualitative و Quantitative |
| استخدام النسب المالية | النسب المالية أساس التقييم |

### 2.2 الفجوات والاختلافات ⚠️

| الجانب | وكالات التصنيف | Bonds Global الحالي |
|---|---|---|
| **الترخيص والرقابة** | مرخصة وخاضعة لرقابة هيئات مالية | نموذج داخلي، غير مرخص كوكالة تصنيف |
| **حجم البيانات التاريخية** | عقود من بيانات التخلفات | لا يوجد تاريخ تخلفات لمعايرة النموذج |
| **التأثير السوقي** | تحركات التصنيف تؤثر على أسعار السندات والفائدة | التصنيف داخلي يؤثر على قرار المنصة فقط |
| **شفافية المنهجية** | منشورة علنًا ومفتوحة للمراجعة | وثيقة داخلية يمكن تحسين شفافيتها |
| **Surveillance** | مراقبة مستمرة وتحديثات دورية | غير مبرمجة تلقائيًا بعد |
| **Issuer vs Issue** | تمييز واضح بين الجهة والإصدار | حاليًا يركز على المقترض/المشروع فقط |
| **Outlook** | توقع اتجاهي مستقبلي | غير موجود حاليًا |
| **Stress Testing** | اختبارات ضغط افتراضية | غير موجودة حاليًا |

### 2.3 موقع Bonds Global في السوق

```text
الوكالات العالمية ← تصنيف مؤسسي/سوقي مرخص
        ↓
البنوك والممولين ← نماذج ائتمانية داخلية (Credit Scoring)
        ↓
Bonds Global ← أداة مساعدة للمقترض/المستثمر لتقدير الجدارة الائتمانية
```

Bonds Global ليس منافسًا لوكالات التصنيف العالمية، بل هو **أداة تقييم أولي ومساعد قرار** للمقترضين الصغار والمتوسطين الذين لا يحصلون على تصنيف من Moody's أو S&P.

## 3. تقييم الإطار الحالي: المحتوى

### 3.1 نقاط القوة

- تغطية شاملة للفئات الثلاث (فرد، ناشئة، SME).
- أوزان واضحة لكل بُعد.
- نماذج رياضية بسيطة وقابلة للتنفيذ.
- قوائم تحقق عملية.
- ربط واضح بـ Bonds Global (Bankability Score, Funding Readiness, CRM).

### 3.2 نقاط تحتاج تحسين

| النقطة | السبب |
|---|---|
| **غياب Calibration** | النطاقات (مثل DTI ≤ 40%) افتراضية ولم تُختبر على بيانات حقيقية. |
| **غياب Stress Testing** | لا يوجد سيناريو للأزمات (تراجع الإيرادات 30% مثلًا). |
| **غياب Outlook** | لا يوجد توقع اتجاهي للتصنيف. |
| **عدم تمييز Issuer/Issue** | يُقيّم المقترض والمشروع كأنهما كيان واحد. |
| **غياب Migration Matrix** | لا يوجد احتمالية انتقال من تصنيف إلى آخر مع الوقت. |

## 4. تقييم الأداء البصري والتصميمي

### 4.1 التقييم الحالي للملف `CREDITWORTHINESS_FRAMEWORK.md`

| الجانب | الدرجة | الملاحظات |
|---|---|---|
| **البنية المنطقية** | ⭐⭐⭐⭐⭐ | أقسام واضحة ومترابطة |
| **سهولة القراءة** | ⭐⭐⭐⭐☆ | الجداول تساعد، لكن وجود كثير من النصوص يمكن تقليله |
| **التصميم البصري** | ⭐⭐⭐☆☆ | ملف markdown تقليدي، لا يوجد ألوان أو رسوم توضيحية |
| **التفاعلية** | ⭐⭐☆☆☆ | لا يوجد charts أو gauges أو infographics |
| **المقارنة المرئية** | ⭐⭐⭐☆☆ | لا يوجد رسم يوضح الفرق بين الفئات الثلاث |

### 4.2 ما ينقص التصميم البصري حاليًا

1. **Risk Heat Map** ملونة لتوضيح مستويات الخطورة.
2. **Score Gauge** لعرض الدرجة الائتمانية بشكل بصري.
3. **Breakdown Chart** يوضح مساهمة كل بُعد في الدرجة النهائية.
4. **Comparison Cards** لمقارنة الأفراد vs الناشئات vs SMEs.
5. **Methodology Flowchart** يشرح كيف يتم حساب الدرجة خطوة بخطوة.

## 5. توصيات للارتقاء إلى مستوى احترافي أعلى

### 5.1 على مستوى المنهجية

1. **إضافة Outlook** لكل تقييم:
   - `Stable`، `Positive`، `Negative`، `Developing`.
2. **تمييز Issuer Rating عن Issue/Project Rating**:
   - `Client Credit Score` للعميل.
   - `Project Bankability Score` للمشروع.
3. **إضافة Stress Testing**:
   - سيناريو أساسي، متessimistic، optimistic.
4. **إضافة Migration Matrix**:
   - احتمالية تحسن/تدهور التصنيف خلال 12 شهرًا.
5. **توثيق المنهجية علنًا**:
   - نشر Methodology Document يشرح الأوزان والافتراضات.
6. **إجراء Backtesting**:
   - عند توفر بيانات كافية، مقارنة التوقعات بالنتائج الفعلية.

### 5.2 على المستوى البصري

1. **إنشاء Scorecard Dashboard**:
   - درجة كبيرة في المنتصف.
   - أشرطة تقدم لكل بُعد.
   - شارة لونية للتصنيف.
2. **استخدام Risk Heat Map**:
   - أخضر/أصفر/برتقالي/أحمر للمخاطر.
3. **Comparison View**:
   - بطاقات جانبية لمقارنة الأفراد والناشئات والـ SMEs.
4. **Methodology Disclosure Panel**:
   - قسم قابل للطي يشرح كيف تم حساب الدرجة.
5. **PDF Report**:
   - تقرير احترافي قابل للطباعة يشبه تقارير S&P/Moody's.

## 7. الخلاصة

| الجانب | وضع Bonds Global |
|---|---|
| **المنافسة مع Moody's/S&P/Fitch** | لسنا منافسين؛ نحن أداة مساعدة للقرار للمقترضين غير المشمولين بوكالات التصنيف. |
| **المحتوى المنهجي** | جيد وشامل، يحتاج إلى Calibration و Stress Testing و Outlook. |
| **التصميم البصري** | تقليدي ويمكن تحسينه كثيرًا عبر Scorecards و Heat Maps و PDF Reports. |
| **الخطوة التالية المقترحة** | إضافة `Outlook`، وفصل `Issuer` عن `Issue`، وبناء UI Scorecard احترافي. |

**الهدف النهائي:** أن يصبح تقييم Bonds Global **مصغّرًا مهنيًا (light-weight professional rating)** للمشاريع الصغيرة والمتوسطة، وليس بديلًا عن وكالات التصنيف العالمية.
