## 1. الرؤية

مستودع معرفي اقتصادي شامل يحتوي على أفضل الممارسات، الأنظمة، اللوائح، الاشتراطات، المعايير، المخاطر، المؤشرات، التكاليف الخفية، أسباب الفشل، عوامل النجاح، KPIs، والدروس المستفادة. يتم تحديثه دون الحاجة إلى تحديث النظام.

## 4. أنواع كائنات المعرفة

| الكائن | الوصف | مثال |
|---|---|---|
| **Best Practice** | أفضل طريقة معتمدة لأداء نشاط. | "نسبة OCC للمطاعم 60-70%". |
| **Regulation** | نظام أو لائحة. | "ترخيص البلدية مطلوب قبل التشغيل". |
| **Requirement** | اشتراط محدد. | "مساحة 300 م² كحد أدنى لمستشفى صغير". |
| **Standard** | معيار دولي أو محلي. | "IFRS 16 للإيجارات". |
| **Risk** | مخاطر قطاعية. | "تقلب أسعار المواد الخام". |
| **Indicator** | مؤشر اقتصادي. | "معدل الإشغال السنوي". |
| **Hidden Cost** | تكاليف غير واضحة. | "رسوم الترخيص، ضمانات البنك". |
| **Failure Factor** | سبب شائع للفشل. | "عدم دراسة الطلب المحلي". |
| **Success Factor** | عامل نجاح. | "موقع مرتفع المردود". |
| **KPI** | مقياس أداء. | "EBITDA Margin". |
| **Lesson Learned** | درس من مشروع حقيقي. | "التوسع السريع أدى إلى تدهور الجودة". |

---

## 5. هيكلة التصنيف

كل كائن معرفة يُصنف حسب:

- **Sector**: مطاعم، صحة، تعليم، صناعة...
- **Country**: SA، AE، US...
- **Asset Type**: عقار، مصنع، خدمة...
- **Lifecycle Stage**: تأسيس، تشغيل، توسع، إغلاق.
- **Confidence**: A-D.
- **Validity Period**: تاريخ البداية والنهاية.

---

## 6. آلية التحديث

| المصدر | الطريقة | التكرار |
|---|---|---|
| فرق المحتوى | Manual curation | مستمر |
| AI extraction | استخراج من تقارير ومواقع | يومي/أسبوعي |
| Legal updates | مراقبة الأنظمة | فوري عند الصدور |
| User feedback | تقييم النتائج | مستمر |
| External experts | مراجعة محتوى | ربعي |

---

## 7. خط أنابيب الموافقة

```text
Draft → Expert Review → Legal Review → Approval → Publish → Distribute
```

- لا يُنشر أي محتوى دون مراجعة.
- يُحتفظ بتاريخ النشر والمراجع.
- يمكن سحب أي كائن معرفة إذا تبين خطؤه.
