## 1. الرؤية

كتالوج موحد يصنف جميع بيانات BONDS حسب القطاع والدولة والمدينة والمصدر ونوع البيانات ودرجة الثقة، بحيث تكون كل بيانة قابلة للاكتشاف والتتبع.

---

## 2. أبعاد التصنيف

| البُعد | الوصف |
|---|---|
| **القطاع** | المجال الاقتصادي (عقار، مطعم، مصنع...). |
| **الدولة** | ISO-3166 alpha-2. |
| **المدينة** | City ID داخل الدولة. |
| **المصدر** | API، ملف، قاعدة بيانات، يدوي. |
| **نوع البيانات** | سعر، مؤشر، لائحة، إحصاء، حدث. |
| **درجة الثقة** | A-D. |
| **طريقة الجلب** | API، Crawler، Manual، Partner. |
| **آخر تحديث** | تاريخ/وقت. |
| **تكلفة الحصول** | مجاني/مدفوع/اشتراك. |
| **شروط الاستخدام** | رخصة المصدر. |

---

## 5. قواعد التصنيف

- كل dataset يجب أن يحمل `dataset_id` فريد.
- كل dataset يُصنف حسب القطاع والدولة على الأقل.
- لا يُسمح بوجود dataset دون مصدر واضح.
- يجب تحديث `last_updated` تلقائياً عند كل جلب.

---

## 6. الاستخدام

- البحث عن البيانات حسب القطاع أو الدولة.
- تقييم جودة وثقة البيانات قبل الاستخدام.
- تتبع Lineage ومصادر البيانات.
- دعم قرارات Live Intelligence Platform.
