# تقرير تحسين تجربة المستخدم — UX Improvement Report

> **البرنامج:** BONDS Product Transformation Program (PTP) — Wave 2  
> **التاريخ:** 2026-07-02

---

## 1. المشكلة قبل Wave 2

كانت بوابة العميل تعرض:

- Dashboard عامة بإحصائيات وتحليلات AI منفصلة.
- قائمة مشاريع بسيطة لا تُظهر المرحلة أو الخطوة التالية.
- إنشاء مشروع يتطلب حقولاً محدودة ولا يرتبط بالمحفظة.
- مصطلحات تقنية (`DSCR`, `NPV`, `capex`) دون شرح.
- قوائم مدن يدوية أو مكررة.

النتيجة: المستخدم لا يرى رحلة واضحة، ويعيد إدخال البيانات، ولا يعرف ما الخطوة التالية.

---

## 2. التحسينات المطبقة

### 2.1 رحلة المشروع كمحور رئيسي

البوابة الجديدة تعرض:

- قائمة المشاريع مع مرحلة كل مشروع.
- شريط رحلة يوضح: الفكرة → الجدوى → التقييم → التمويل → الجاهزية → النشرة → مراجعة AI → المستثمرون → غرفة البيانات → جاهز للنشر.
- الخطوة التالية الموصى بها (`nextBestAction`) في كل بطاقة.

### 2.2 Wizard إنشاء المشروع

خطوات واضحة:

1. بيانات المشروع (اسم، قطاع، نشاط، دولة، محافظة، مدينة).
2. البيانات المالية (عملة، رأس المال، إيرادات، صافي ربح).
3. مراجعة قبل الإنشاء.

جميع الحقول تحمل `label` واضحاً، وقوائم المواقع موحدة عبر `BondsGeo`.

### 2.3 لغة رجل الأعمال

- `DSCR` → "نسبة تغطية خدمة الدين (DSCR)"
- `NPV` → "القيمة الحالية الصافية (NPV)"
- `capital` → "رأس المال الاستثماري"
- `annual_profit` → "صافي الربح السنوي"

المصدر: `lib/i18n/fields.js`.

### 2.4 توحيد المواقع

- اعتماد `v3/master-data` كمصدر وحيد.
- استخدام `calculators/shared-geo.js` لجميع قوائم الدول/المدن في البوابة.
- إصلاح تكرار `الأحساء`.

### 2.5 تحسينات بصرية

- بطاقات مشاريع بمؤشرات واضحة.
- حالات فارغة موجهة (CTA لإنشاء مشروع).
- تصميم متجاوب للجوال.
