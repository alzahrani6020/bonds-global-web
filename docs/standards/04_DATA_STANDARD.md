# 04 — Data Standard (معيار البيانات)

## الهدف
بناء طبقة بيانات موحدة تُخزّن كل بيانات المستخدم مرة واحدة، مع تتبع مصدر كل معلومة وإمكانية تعديلها بوضوح.

## النطاق
- جميع مدخلات المستخدم.
- جميع البيانات الخارجية (Live Data).
- جميع الجداول والحقول في Supabase.
- جميع ملفات JS التي تحمل بيانات ثابتة.

---

## القواعد الإلزامية (Mandatory)

### M1 — Single Source of Truth
- كل بيانات المستخدم تُخزن مرة واحدة فقط.
- لا يُسمح بتكرار نفس الحقل في جدولين مختلفين.

### M2 — Data Lineage
- كل بيانة خارجية يجب أن تحمل:
  - `source`
  - `collected_at`
  - `confidence_score`
  - `valid_until`
  - `raw_value`

### M3 — Smart Data Override
- يمكن للمستخدم تعديل أي بيانة.
- عند التعديل يُسجل:
  - القيمة الأصلية.
  - القيمة الجديدة.
  - سبب التعديل.
  - المستخدم الذي عدّل.
  - وقت التعديل.
- يُعاد حساب جميع النتائج المتأثرة تلقائياً.

### M4 — لا بيانات ثابتة في الكود
- يُمنع وضع قوائم طويلة من البيانات في ملفات JS (مثل أسعار دول، منصات، مؤشرات) إلا إذا كانت معايير مرجعية.
- البيانات الديناميكية تأتي من قاعدة البيانات أو Live Data Engine.

### M5 — صلاحية البيانات
- كل بيانة خارجية يجب أن تحمل تاريخ صلاحية.
- النظام يحذر من البيانات القديمة.

---

## القواعد الموصى بها (Recommended)

### R1 — Data Quality Score
- كل مجموعة بيانات تحصل على درجة جودة (0-100).

### R2 — Provenance Graph
- يمكن تتبع أي نتيجة إلى البيانات التي أدت إليها.

---

## أمثلة

### ✅ صحيح
```json
{
  "averageSellingPrice": 1200000,
  "source": "KAPSARC Real Estate Index",
  "collected_at": "2026-06-01",
  "confidence_score": 0.85,
  "valid_until": "2026-09-01"
}
```

### ❌ خاطئ
```js
const countryData = { sa: { price: 1200000 }, ae: { price: 1100000 } };
```

---

## كيفية القياس
1. البحث عن المصفوفات والكائنات الكبيرة في ملفات JS.
2. مراجعة جداول Supabase بحثاً عن أعمدة متكررة.
3. فحص كل بيانة خارجية لوجود مصدر وتاريخ.

## Severity عند المخالفة
- **Critical:** بيانات حساسة ثابتة في الكود.
- **High:** نفس البيانات مخزنة في جدولين.
- **Medium:** بيانات خارجية بدون مصدر أو تاريخ.
- **Low:** عدم وجود confidence score.

## طريقة الإصلاح
- نقل البيانات إلى جداول Supabase.
- إضافة أعمدة المصدر والتاريخ.
- بناء Smart Override logger.
